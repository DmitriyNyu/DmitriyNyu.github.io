Одна метка у значенияOne label per value

23 окт. 202623 Oct 2026 · Открыть на сайтеOpen on the site

ЦельGoal

Инвестор читает факты лота и проекта без визуального шума: видно значение и одну метку, откуда оно; подробности источника — по нажатию.An investor reads lot and project facts without visual noise: the value and one label saying where it comes from; source details on tap.

ЗадачаProblem

У каждого значения стояли две текстовые метки подряд: «заявление продавца» и «i продавец», у пересчёта валют — «посчитано нами, курс на …» и «i посчитано нами». В тексте части значений ещё раз было написано «(заявление продавца)». В обзоре лота на 15 строк приходилось 22–29 текстовых меток.Every value carried two text labels in a row: «seller's claim» and «i seller»; a currency conversion — «derived, rate of …» and «i derived». Some value texts said «(seller's claim)» once more. A lot overview had 22–29 text labels for 15 rows.

Как решилиHow it was solved

  • Если у значения уже есть метка типа («заявление продавца», «посчитано нами»), значок источника рядом — только «i»: по нажатию открываются источник, дата проверки и цитата; экранный диктор по-прежнему читает тип источника.If a value already has a type label («seller's claim», «derived»), the source tag next to it is just «i»: tapping opens the source, check date and quote; a screen reader still reads the source type.
  • Повторное «(заявление продавца)» в конце текста значения не показывается — метка рядом говорит то же самое. Данные не менялись.A trailing «(seller's claim)» in the value text is not shown — the label next to it says the same. The data is unchanged.
  • Заявления продавца по-прежнему помечены текстом, а не только цветом (требование ТЗ); автоматическая проверка это подтверждает. На телефоне значок «i» стал крупнее — 28 px.Seller claims are still marked with text, not only colour (a requirement); the automated check confirms it. On a phone the «i» tag is bigger — 28 px.
  • Итог: в обзоре лота 13–16 текстовых меток вместо 22–29.Result: a lot overview has 13–16 text labels instead of 22–29.
