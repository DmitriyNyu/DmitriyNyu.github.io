Таблица юнитов: только то, что известноUnits table: only what is known

23 окт. 202623 Oct 2026 · Открыть на сайтеOpen on the site

ЦельGoal

На странице проекта инвестор сравнивает юниты между собой: тип, площадь, цену, цену за метр. Это третья часть цели сайта — открыть проект и увидеть всё о нём.On a project page an investor compares its units: type, area, price, price per square metre. This is the third part of the site's goal — open a project and see everything about it.

ЗадачаProblem

В таблице Kempinski Residences Astoria на 5 строк было 12 ячеек «нет данных» и «цена по запросу у продавца», колонка «Этаж» была пустой во всех строках, заголовки числовых колонок не стояли над своими числами. В таблице всех юнитов таких ячеек было 514. На телефоне таблица из 6–7 колонок не помещалась и ломала слова по буквам.The Kempinski Residences Astoria table had 12 «no data» and «price on request from the seller» cells in 5 rows, the «Floor» column was empty in every row, and numeric headers did not sit over their numbers. The all-units table had 514 such cells. On a phone a 6–7 column table did not fit and broke words letter by letter.

Как решилиHow it was solved

  • Колонка, пустая во всех строках, не рисуется (у Astoria ушёл «Этаж»).A column that is empty in every row is not drawn (Astoria lost «Floor»).
  • Пропуск — серый прочерк, экранный диктор читает «нет данных»; вместо «цена по запросу у продавца» — «по запросу».A missing value is a grey dash that a screen reader reads as «no data»; «price on request from the seller» became «on request».
  • Числа и их заголовки выровнены по правому краю, цифры табличные.Numbers and their headers are right-aligned, with tabular figures.
  • На телефоне каждая строка — двухстрочный элемент списка: тип и цена сверху, площадь, цена за м² и дата ниже, «Открыть» и «сравнить» справа. Так делают мобильные версии инструментов с таблицами.On a phone each row is a two-line list item: type and price on top, area, price per m² and date below, «Open» and «compare» on the right — as mobile versions of table tools do.
  • Итог: у Astoria 6 колонок вместо 7, видимых «нет данных» — 0 (было 12), в таблице всех юнитов — 0 (было 514).Result: Astoria has 6 columns instead of 7 and 0 visible «no data» (was 12); the all-units table has 0 (was 514).
