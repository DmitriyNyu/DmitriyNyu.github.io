Сравнение: только то, чем лоты отличаютсяCompare: only what differs

23 окт. 202623 Oct 2026 · Открыть на сайтеOpen on the site

ЦельGoal

Инвестор выбирает 2–4 лота и за несколько секунд видит, чем они отличаются. Это вторая часть цели сайта — удобно сравнивать.An investor picks 2–4 lots and sees in seconds how they differ. This is the second part of the site's goal — easy comparison.

ЗадачаProblem

Таблица сравнения всегда показывала все 22 поля. Строки, где ни у одного лота нет данных, и строки с одинаковым значением у всех лотов занимали место наравне с важными. У двух лотов одного проекта (Kempinski Residences Astoria) различались всего 3 строки из 22 — их приходилось искать.The comparison table always showed all 22 fields. Rows with no data for any lot and rows where every lot had the same value took as much room as the important ones. Two lots of the same project (Kempinski Residences Astoria) differed in only 3 rows out of 22 — and you had to find them.

Как решилиHow it was solved

  • Строки, где данных нет ни у одного выбранного лота, скрыты: сравнивать там нечего. Над таблицей написано, сколько строк скрыто.Rows where none of the selected lots has data are hidden: there is nothing to compare. A line above the table says how many are hidden.
  • Переключатель «Только различия» (как в сравнении товаров в интернет-магазинах) скрывает строки, где у всех лотов одно и то же значение; выбор запоминается в браузере.A «Differences only» switch (as in online-shop product comparison) hides rows where every lot has the same value; the choice is remembered in the browser.
  • Значения сравниваются по тексту, без меток и цитат источников — одинаковые факты из разных объявлений считаются одинаковыми.Values are compared by their text, without labels and source quotes — the same fact from different listings counts as the same.
  • Итог: три лота из разных городов — 16 строк вместо 22; два лота одного проекта — 10 строк, а с «Только различия» — 3 (цена, цена за м², тип номера).Result: three lots from different cities — 16 rows instead of 22; two lots of one project — 10 rows, and 3 with «Differences only» (price, price per m², room type).
