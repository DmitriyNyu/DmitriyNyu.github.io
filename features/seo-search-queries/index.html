Заголовки отвечают на «апарт-отель в городе, доходность»Titles answer «apart-hotel in a city, yield»

14 нояб. 202614 Nov 2026 · Открыть на сайтеOpen on the site

ЦельGoal

Человек ищет «апарт-отель Стамбул доходность» или «Аквилон Signal доходность» и видит в заголовке вкладки название, город и то, что реально есть в данных: число лотов, программу аренды, заявленную доходность.A person searching for an apart-hotel in a city, or a project plus yield, sees a title with the name, the city and only the facts the data actually has: lot count, a rental programme, a claimed yield.

ЗадачаProblem

Заголовок вкладки называл тип и цену и не содержал город и слово «доходность», хотя так ищут. Со страницы проекта не было перехода к другим проектам того же города.The browser title named the type and the price and did not name the city or yield, which is how people search. A project page did not link to the other projects in the same city.

Как решилиHow it was solved

  • У главной, города и проекта свой заголовок и описание из данных этой страницы. Описание — одно-два предложения. Город, который уже есть в имени проекта, второй раз не пишется. Нет программы аренды или заявленной доходности — этих слов нет. Отзывов в данных нет, слово «отзывы» не пишем.The home page, a city and a project each have a title and a description from that page's data. No rental programme or claimed yield — those words are absent. The data has no reviews, so the word is not used.
  • На странице проекта крошки ведут страна → город → проект, и рядом список «Другие апарт-отели в этом городе». С главной есть ссылка на каждый город, со страницы города — на каждый проект.A project page breadcrumbs run country, city, project, with a list of other apart-hotels in that city. The home page links every city, and a city page links every project.
