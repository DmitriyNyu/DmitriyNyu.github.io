Заголовок лота — юнит, проект — один раз над нимThe lot heading is the unit, the project once above it

25 окт. 202625 Oct 2026 · Открыть на сайтеOpen on the site

ЦельGoal

Инвестор на странице лота сразу видит, что это за юнит («2+1 · 111 м²»), а проект — ссылкой прямо над заголовком, как бренд над названием товара.An investor on a lot page sees at once which unit it is («2+1 · 111 m²»), with the project as a link right above the heading, like a brand above a product name.

ЗадачаProblem

Название проекта стояло на экране два раза подряд: последним звеном «хлебных крошек» (на телефоне — отдельной строкой) и в начале заголовка «Hotel Homes Istanbul (Esenyurt) · 2+1 · 111 м²», который из-за этого занимал две строки. У лотов без названия проекта — «Проект не указан продавцом» в крошках и «Проект не указан продавцом (Стамбул) · 1+1 · 74 м²» в заголовке.The project name was on screen twice in a row: as the last breadcrumb (its own line on a phone) and at the start of the heading «Hotel Homes Istanbul (Esenyurt) · 2+1 · 111 m²», which took two lines because of it. Lots without a named project had «Project not named by the seller» in the crumbs and «Project not named by the seller (Istanbul) · 1+1 · 74 m²» in the heading.

Как решилиHow it was solved

  • Заголовок на экране — юнит: «2+1 · 111 м²». Проект — ссылкой в крошках прямо над ним.The heading on screen is the unit: «2+1 · 111 m²». The project is the breadcrumb link right above it.
  • Для программ экранного доступа, поиска и вкладки браузера заголовок по-прежнему полный — с проектом. Если тип и площадь неизвестны, заголовок остаётся полным.For screen readers, search and the browser tab the heading is still full — with the project. When neither type nor area is known, the heading stays full.
  • Итог на 390 px: заголовок 2 строки → 1, вкладки лота выше ещё на 27 px (489 → 462).Result at 390 px: the heading 2 lines → 1, the lot's tabs another 27 px higher (489 → 462).
