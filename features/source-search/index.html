Поиск домена в каталоге источниковFind a domain in the source catalogue

25 окт. 202625 Oct 2026 · Открыть на сайтеOpen on the site

ЦельGoal

Инвестор, который хочет проверить источник факта, находит его домен в каталоге одним вводом — с типом источника, числом фактов, датой проверки и адресами страниц.An investor checking where a fact comes from finds its domain in the catalogue in one entry — with the source type, number of facts, check date and page addresses.

ЗадачаProblem

Каталог — 97 доменов подряд по алфавиту; на телефоне 390 px список занимает от 337 до 11 751 px страницы. Найти нужный домен можно было только прокруткой или поиском браузера; чипы сужали список лишь по типу (продавцов — 56).The catalogue is 97 domains in alphabetical order; on a 390 px phone the list runs from 337 to 11,365 px down the page. A domain could be found only by scrolling or the browser's find; the chips narrowed the list by type only (56 sellers).

Как решилиHow it was solved

  • Поле «Найти домен» над чипами типов: «alanya» оставляет alanya.gov.tr и open-meteo.com (его адрес с «Alanya»), «gov.tr» — 28 доменов. Ищет по домену и по адресам страниц, можно вставить адрес целиком с https://www.A «Find a domain» field above the type chips: «alanya» leaves alanya.gov.tr and open-meteo.com (its address has «Alanya»), «gov.tr» — 28 domains. It looks at the domain and the page addresses; a whole address with https://www. can be pasted.
  • Поиск работает вместе с выбранным типом. Если среди этого типа совпадений нет — так и сказано, и кнопка «Искать во всех типах (28)».The search works together with the chosen type. When that type has no match, it says so, with a «Search all types (28)» button.
  • Ничего не найдено — «По запросу «…» источников нет» и кнопка «Очистить поиск», которая снимает запрос и возвращает список выбранного типа (при «Все» — все 97). Без JavaScript поля нет, список виден целиком.Nothing found — «No sources match «…»» and a «Clear the search» button that removes the query and brings back the list of the chosen type (all 97 with «All»). Without JavaScript there is no field and the whole list shows.
