Юнит — ссылка своим названием, без «Открыть»A unit links by its name, no «Open»

25 окт. 202625 Oct 2026 · Открыть на сайтеOpen on the site

ЦельGoal

Инвестор сразу видит, что юнит в списке можно открыть: его название («2+1», «Апартаменты, 3 спальни») выглядит как ссылка, как название проекта в карточке. В строке нет лишних слов.An investor sees at once that a unit in a list can be opened: its name («2+1», «Apartments, 3 bedrooms») looks like a link, as a project name does in a card. No extra words in the row.

ЗадачаProblem

В каждой строке юнита — в карточках каталога, во «Всех юнитах», на страницах проекта и лота — стояла отдельная ссылка «Открыть», а название юнита было обычным текстом. В каталоге 230 ссылок с одним и тем же текстом «Открыть»: программа экранного доступа зачитывает их одинаково, и непонятно, куда ведёт каждая (стандарт доступности WCAG 2.4.4).Every unit row — in catalogue cards, «All units», project and lot pages — had a separate «Open» link while the unit's name was plain text. The catalogue had 230 links all named «Open»: a screen reader reads them the same, with no clue where each leads (accessibility standard WCAG 2.4.4).

Как решилиHow it was solved

  • Название юнита — ссылка на его страницу (цвет ссылки, подчёркивание при наведении — как у названия проекта в карточке).The unit's name is the link to its page (link colour, underlined on hover — as a project name in a card).
  • «Открыть» убрано; в последней колонке — только «+ сравнить». Вся строка по-прежнему открывает лот: на телефоне — нажатием, на компьютере — кликом.«Open» is gone; the last column has only «+ compare». The whole row still opens the lot: a tap on a phone, a click on a computer.
  • Если тип не указан — ссылка «тип не указан», а не прочерк.When the type is unknown, the link reads «type not stated», not a dash.
