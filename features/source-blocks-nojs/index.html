Каталог источников без JavaScript на 800–1023 px — адреса во всю ширинуSource catalogue without JavaScript at 800–1023 px — addresses across the full width

26 окт. 202626 Oct 2026 · Открыть на сайтеOpen on the site

ЦельGoal

Инвестор, у которого в браузере выключен JavaScript, на экране 800–1023 px раскрывает «N URL» у домена, чтобы проверить, откуда взяты факты, и читает адреса страниц в одну–три строки, а не столбиком из обрывков.An investor whose browser has JavaScript turned off opens «N URLs» for a domain on an 800–1023 px screen to check where the facts come from, and reads the page addresses in one to three lines, not as a column of fragments.

ЗадачаProblem

С JavaScript открытый список адресов с 800 px идёт на всю ширину строки. Без JavaScript он оставался в последней колонке таблицы, где под текст адреса было 61–208 px. Со всеми раскрытыми списками на 800 px самый длинный адрес занимал 12 строк, 4 строки и больше — 217 из 267 адресов; на 900 px — до 10 строк, 175 адресов; на 1023 px — до 8 строк, 125 адресов.With JavaScript an open list of addresses runs the full width of the row from 800 px. Without JavaScript it stayed in the last column of the table, with 61–208 px for the address text. With all lists opened, at 800 px the longest address took 12 lines and 217 of the 267 addresses took 4 lines or more; at 900 px up to 10 lines, 175 addresses; at 1023 px up to 8 lines, 125 addresses (Russian page: without JavaScript the site is shown in Russian).

Как решилиHow it was solved

  • Без JavaScript до 1023 px каждый домен — отдельный блок, как до 799 px: домен, строка «тип · N фактов · проверено», под ней «N URL» и адреса во всю ширину. Таблица без JavaScript — с 1024 px. На 800, 860, 900, 960 и 1023 px ни один адрес не длиннее 3 строк; всего строк адресов на 800 px — 338 вместо 1 462, на 1023 px — 275 вместо 916. Длиннее не стал ни один адрес.Without JavaScript each domain is a block of its own up to 1023 px, as up to 799 px: the domain, the «type · N facts · checked» line, then «N URLs» and the addresses across the full width. Without JavaScript the table starts at 1024 px. At 800, 860, 900, 960 and 1023 px no address takes more than 3 lines; the addresses take 338 lines in total at 800 px instead of 1,462, and 275 instead of 916 at 1023 px. No address got longer (Russian page).
  • Со всеми раскрытыми списками каталог стал короче: на 800 px — на 19 298 px, на 1023 px — на 8 730. С закрытыми списками он длиннее: с мышью — в 2,3–2,5 раза (800 px: 11 242 px вместо 4 788), на сенсорном экране — в 2,0–2,1 раза (800 px: 11 242 вместо 5 580): у каждого домена друг под другом домен, строка «тип · N фактов · проверено» и кнопка «N URL» высотой 44 px. С JavaScript, до 799 px и с 1024 px ничего не изменилось.With all lists opened the catalogue got shorter: by 19,298 px at 800 px and by 8,730 at 1023 px. With the lists closed it is longer: 2.3–2.5 times with a mouse (800 px: 11,242 px instead of 4,788), 2.0–2.1 times on a touch screen (800 px: 11,242 instead of 5,580): each domain stacks the domain, the «type · N facts · checked» line and a 44 px «N URLs» button. Nothing changed with JavaScript, up to 799 px or from 1024 px (Russian page).
