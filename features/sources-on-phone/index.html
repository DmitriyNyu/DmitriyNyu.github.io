Каталог источников читается на телефонеThe source catalogue reads on a phone

23 окт. 202623 Oct 2026 · Открыть на сайтеOpen on the site

ЦельGoal

Инвестор хочет проверить, откуда взяты факты: сколько источников официальные, а сколько — заявления продавцов, когда их проверяли и какие страницы. Каталог источников — опора доверия к сайту, где каждый факт со ссылкой.An investor wants to check where the facts come from: how many sources are official and how many are seller claims, when they were checked and which pages. The source catalogue is what trust in a site where every fact links to its source rests on.

ЗадачаProblem

На телефоне таблица из пяти колонок не помещалась: заголовки и значения ломались по буквам («Ф а к т о в», «20 26 -10 -2 2»), строка домена занимала 127 px, страница — 13 613 px. На компьютере колонки «Фактов», «Последняя проверка» и «URL» тоже переносились. Выбрать только официальные источники было нельзя — 97 доменов подряд по алфавиту.On a phone the five-column table did not fit: headings and values broke letter by letter («F a c t s», «20 26 -10 -2 2»), a domain row took 127 px and the page 13,613 px. On desktop the «Facts», «Last checked» and «URL» columns wrapped too. There was no way to see only official sources — 97 domains in a row, alphabetically.

Как решилиHow it was solved

  • На телефоне каждый домен — блок: домен крупно, ниже «продавец · 5 фактов · проверено 2026-10-22», под ним «2 URL» высотой 44 px — список страниц раскрывается по нажатию.On a phone each domain is a block: the domain large, then «seller · 5 facts · checked 2026-10-22», then «2 URL», 44 px tall — the page list opens on tap.
  • Над каталогом — чипы типов источника с числом доменов: «Все 97 · официальный 23 · продавец 56 · оператор 4 …»; нажатие оставляет только этот тип.Above the catalogue — source type chips with domain counts: «All 97 · official 23 · seller 56 · operator 4 …»; a tap keeps only that type.
  • На компьютере числа, даты и «N URL» не переносятся: строка 36 px вместо 59, страница 4 300 px вместо 6 302.On desktop numbers, dates and «N URL» no longer wrap: a row is 36 px instead of 59, the page 4,300 px instead of 6,302.
  • Итог: на телефоне ничего не ломается по буквам, строка 110 px вместо 127, страница 11 953 px вместо 13 613; только официальные источники — 23 домена, 3 224 px.Result: nothing breaks letter by letter on a phone, a row is 110 px instead of 127, the page 11,953 px instead of 13,613; official sources only — 23 domains, 3,224 px.
