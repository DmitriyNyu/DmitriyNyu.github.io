Блок проекта на странице лота — «Проект: …», как «Город: …»The project block on a lot page — «Project: …», like «City: …»

25 окт. 202625 Oct 2026 · Открыть на сайтеOpen on the site

ЦельGoal

Инвестор открывает лот и видит поля, которые лот наследует от проекта и города. Два одинаковых по смыслу блока должны и называться одинаково, чтобы заголовок читался как заголовок, а не как обрывок служебной пометки.An investor opens a lot and sees the fields the lot inherits from its project and its city. Two blocks of the same kind should be headed the same way, so a heading reads as a heading, not as a fragment of an internal label.

ЗадачаProblem

На вкладке «Обзор» всех 231 страниц лотов блок проекта начинался со строчной: «проект: Kempinski Residences Astoria», а блок города ниже — с заглавной: «Город: Стамбул». У 84 лотов, где продавец не назвал проект, заголовок повторял слово: «проект: Проект не указан продавцом»; на телефоне 320 px он занимал две строки.On the «Overview» tab of all 231 lot pages the project block started in lower case: «project: Kempinski Residences Astoria», while the city block below started with a capital: «City: Istanbul». On the 84 lots whose seller does not name the project, the heading repeated the word: «project: Project not named by the seller»; on a 320 px phone it took two lines.

Как решилиHow it was solved

  • Заголовок блока проекта — «Проект: …» / «Project: …», как «Город: …» / «City: …». Ссылка на страницу проекта прежняя.The project block heading is «Project: …», like «City: …». The link to the project page is the same.
  • У лота без названного проекта заголовок — одна ссылка «Проект не указан продавцом» (на группу таких лотов на странице города), без «Проект: Проект …»; на 320 px он стал на строку короче (−25 px), в ru и en.On a lot without a named project the heading is one link, «Project not named by the seller» (to the group of such lots on the city page), without «Project: Project …»; at 320 px it is one line shorter (−25 px), in ru and en.
  • Данные не менялись; в сборке изменились только эти 231 заголовок. Замер 231 лота × 320/390/1280 × ru/en: у остальных высота страниц та же, кроме 3 лотов The Superior Suites (Kağıthane) — в ru на 390 px заглавная «П» переносит название на вторую строку (+25 px).Data did not change; in the build only these 231 headings changed. Measured 231 lots × 320/390/1280 × ru/en: other page heights are the same, except 3 lots of The Superior Suites (Kağıthane) — in Russian at 390 px the capital «П» moves the name to a second line (+25 px).
